# Guardião\n\nO Guardião ajuda os assistentes desta mesa a pesquisar bem, seguir as regras e explicar o que fizeram. Não é preciso conhecer a Fábrica nem usar palavras técnicas.\n\n## Como falar com ele\n\nFale ou escreva naturalmente. Por exemplo: “Guardião, a partir de agora, avise quando faltar pesquisa.” Não existe frase obrigatória, formulário ou comando especial. Chamar “Guardião” ajuda a mostrar que você está falando com ele, mas não é obrigatório. Se a instrução estiver clara, ela será registrada; se houver dúvida real, será feita só a pergunta necessária.\n\n## O que ele faz\n\n- Acompanha os assistentes conectados a esta mesa e compartilha as regras vigentes.\n- Incorpora novas regras confirmadas à política e ao guia dos assistentes.\n- Se um assistente concluir que algo é impossível ou exige reiniciar sem pesquisar o suficiente, envia uma advertência e pede evidências; reincidências geram uma tarefa de revisão.\n\n## Ações nesta tela\n\n- **Ativar o Guardião:** inicia o monitor.\n- **Ver se está ativo:** mostra a conexão, o último sinal de funcionamento e os assistentes observados.\n- **Pausar o Guardião:** encerra o monitor e exige confirmação.\n\n## Privacidade e limites\n\nO Guardião só vê o que passa pelo registro desta mesa. Ele não abre dados privados para outras pessoas, não apaga agentes ou dados e não aplica banimentos. Se o serviço que hospeda a mesa for reiniciado, confira o estado e ative-o novamente se necessário.\n
